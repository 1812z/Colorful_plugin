# 全局随机换色 Profile

导入文件：`Random-Color-15s-Lite.zip`。旧的 `Random-Color-15s.zip` 和 `.artemis` 文件不要再导入，8193 个节点超过 Artemis 渐变节点的最小间距限制，可能导致界面卡顿和高 CPU。

先从左侧菜单暂停或删除旧的 **Random Color - 15s Hold and Fade**，不要进入旧效果的编辑页。若软件已卡住，先退出重启。恢复 Rainbow 确认输出正常后，再导入上述 ZIP，激活 **Random Color - 15s Lite**。

如果之前导入的旧版没有亮灯，请在该随机效果的菜单中点击 **Resume（恢复）**。旧生成文件曾继承模板的暂停状态，现已修正为默认不暂停。软件的全局灯效输出也应处于恢复状态。

此 Profile 只使用已安装的 **Color Layer Brush → Solid**，不需要额外插件。导入时通过所有设备的适配规则覆盖当前设备，全局显示同一种颜色。

每轮 15 秒：保持当前颜色 13 秒，然后用 2 秒渐变至下一种颜色，再保持。使用预先随机生成的 16 种颜色，完整序列 4 分钟后循环；不是运行时无限随机。可重新运行生成脚本获得另一组随机序列。

已经检查 ZIP 完整性、单层纯色画刷引用、所有设备适配规则，以及全部 16 轮的 13 秒保持 / 2 秒渐变时间。33 个节点间距均大于 0.0011，避开 Artemis 的 0.001 最小间距限制。仍需在 Artemis 中实际导入并确认显示；这些静态检查不等于已完成界面运行验证。
